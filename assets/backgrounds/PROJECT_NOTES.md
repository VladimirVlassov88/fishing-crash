# Fishing-Crash

## Текущий статус
- HTML/CSS/JS browser prototype.
- Основная логика работает: заброс как спин, пусто / малёк / рыба.
- Малёк даёт небольшой возврат без crash-фазы.
- Настоящая рыба запускает crash-фазу.
- Crash point скрыт от игрока.
- Есть ручной cashout "В садок".
- Есть auto cashout.
- Есть reward popup: иконка рыбы + сумма улетает вверх.
- Есть сильный bite effect: КЛЁВ, shake, всплеск.
- Фон: cinematic lake background.
- Подводный слой подключён.
- Эффекты water wake/trail лучше отключать, если выглядят как прожектор.
- Рыбьи иконки подключены, но нужно стабилизировать загрузку и убрать белый фон окончательно.

## Философия дизайна
- Не делаем скучную казино-картинку.
- Игра должна давать ощущение ночной рыбалки: ожидание, клёв, борьба, награда.
- Визуал должен быть атмосферным, чистым, премиальным, без лишнего шума.
- Клёв = главный эмоциональный пик.
- Награда должна визуализироваться, а не только уходить в баланс.

## Следующие задачи
1. Стабилизировать загрузку иконок рыб.
2. Убрать белый фон у рыб окончательно.
3. Проверить mobile layout.
4. Доработать историю раундов.
5. Позже вернуться к эффекту движения воды, но без прожекторного пятна.

## Важно не ломать
- игровую механику;
- hidden crash logic;
- auto cashout;
- reward popup;
- bite effect;
- текущий фон и общий стиль;
- расположение кнопок: ставка слева, главные кнопки по центру, auto cashout справа.
